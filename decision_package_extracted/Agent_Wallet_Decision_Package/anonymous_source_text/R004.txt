L01913 ## 4. Academic & Security Research Highlights (citations affect design)
L01914 - **SoK: Security of Autonomous LLM Agents in Agentic Commerce** (arXiv 2604.15367, Apr–May 2026): Systematises 12 cross-layer attack vectors across agent integrity, transaction authorisation, inter-agent trust, market manipulation, compliance. **Design implication:** Separate planning from authorisation; never let the LLM hold unrestricted signing power.
L01915 - **Whispers of Wealth / AP2 prompt-injection red-teaming** (arXiv 2601.22569 & follow-ups): 100 % success on ranking manipulation via indirect injection; cryptographic mandates alone insufficient. **Implication:** Policy must be enforced *before* the LLM’s output reaches the signer.
L01916 - **APort Vault / Open Agent Passport benchmark** (arXiv 2609.22076, Sep 2026): Large-scale CTF of payment authorisation attacks; deterministic pre-action checks dramatically reduce success. **Implication:** Prefer deterministic policy engines over pure LLM judgment.
L01917 - **AI Agents in Cryptoland** (ePrint 2025/526): Context manipulation (prompt + memory + external feeds) leads to unintended transfers; prompt defenses insufficient. **Implication:** Immutable audit + emergency stop + maximum-loss bounds.
L01918 - **ERC-8004 empirical study** (arXiv 2606.26028): Rapid identity growth but sparse feedback/validation usage. **Implication:** Useful for discovery/reputation but not a substitute for hard spend controls.
L01919 **Core architectural principle derived:**  
L01920 AI planning → Trusted policy enforcement (on-chain module or enclave) → Simulation → Authorisation → Protected signing → Execution → Receipt verification + immutable audit. The LLM never sees the private key or unrestricted spend authority.
