# Evidence bundle

Start with Agent_Wallet_Decision_Report.md. It contains all 18 requested deliverable areas and the full inventory/crosswalk. Executive_Decision_Memo.md is the short decision view.

research_ledgers.json is the authoritative structured companion: ideas, hybrids, claim statuses, primary source records, rubric inputs/ranges, scenario weights/orders, source URLs and product/research mention occurrences. original_concept_crosswalk.json maps recoverable source slots to normalized IDs. source_table_rows.json preserves all supplied table rows for omission review. anonymous_source_text preserves all supplied anonymous report blocks and anchors.

Report mentions are not verified facts. Some reports contain missing text and invalid or inaccessible citation markers. Do not reuse their internal web citation IDs as current external citations. Use S001–S040 in the report; no prototype result is asserted.

Omission review procedure: inspect each source concept slot against the crosswalk, inspect single-report ideas separately, and compare any newly recovered source text before changing stable IDs. Raw-table and full-text preservation permits independent review of disputed merges. This is traceability, not a proof that absent source material was recovered.

No wallet code, credentials, funds or external messages are included or created. The scripts used to assemble the research artifacts are packaging utilities, not implementation of any proposed wallet.
